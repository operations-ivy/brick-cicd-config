# Art

- `earth.png`: "Pixel Earth Animation" by Slime Games Studios, the 32x32 set
  (20 frames, joined side by side into one sheet), from
  https://opengameart.org/content/pixel-earth-animation. License: CC0
  (public domain), https://creativecommons.org/publicdomain/zero/1.0/.
  Credited here anyway, with thanks.
- `n64-<planet>.png` and `n64-<planet>-ringed.png`: "N64 Planets" by n64guy,
  from https://opengameart.org/content/n64-planets. License: CC0 (public
  domain); "Credit as n64guy would be nice but is not necessary", so: thank
  you, n64guy. Each sheet is every other frame of the original 60 (30 frames,
  one full turn), shrunk from 128x128 to 64x64 by averaging 2x2 blocks.
